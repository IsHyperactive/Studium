# Contribuir a Studium

Gracias por contribuir.

## Antes de empezar
- Revisa [las incidencias abiertas](https://github.com/IsHyperactive/Studium/issues) para evitar duplicar trabajo.
- Para cambios grandes, abre primero una incidencia y describe la propuesta.
- No introduzcas dependencias, funciones o cambios de arquitectura sin justificar y revisar su impacto.

## Flujo de trabajo
1. Crea una rama descriptiva desde `main`, por ejemplo `feat/import-material` o `fix/reader-layout`.
2. Mantén cada commit enfocado y pequeño.
3. Usa mensajes en español con prefijo: `feat:`, `fix:`, `docs:`, `ci:` o `chore:`.
4. Abre un Pull Request contra `main` y completa la plantilla.
5. Explica las pruebas realizadas y las plataformas afectadas.

## Calidad
- No declares que una compilación o prueba pasó si no se ejecutó.
- No incluyas secretos, credenciales, archivos locales ni datos personales.
- Conserva la estructura existente salvo que el cambio aprobado requiera modificarla.
- Prioriza accesibilidad, controles táctiles cómodos y adaptación a distintos tamaños de pantalla.

## Estado actual
El repositorio aún no contiene el código de la aplicación. Hasta que se incorpore, las contribuciones deben limitarse a documentación y preparación del repositorio, salvo que se añada código de forma explícita.
